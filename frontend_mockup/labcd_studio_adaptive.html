Configure Adaptive control

Clarifier → Designer → Tuner design a nonlinear adaptive controller (SMC or backstepping) straight from the plant's state equations — no MPC plugin, no linearization. Confirm the plant, the shared simulation setup, and what's uncertain, then hand off to the pipeline.

1Plant & system structure
Pulled from AgentPlant's confirmed metadata (states, equations, parameters) — the same object plant_compiler.generate_adaptive_spec() reads. Equation-driven only; MPC plugin fields are out of scope here.
Backed by ArtifactStore.list_artifacts() / get_adaptive_spec(artifact_id) — the plant + pre-launch a real artifact would already carry from Case Studies' pre-launch step.
2Pre-launch · shared simulation config
Same schema as pre_launch_panel.py — shared with the MPC module. Trajectory knobs compile into references: [{output, expr}] via PlantCompiler._build_references().
Maps to pre_launch in the artifact ({total_simulation_time, solver_sample_time, initial_state, default_target, trajectory_*}). Amplitude / frequency / offset are ignored when mode is reg.
Preview Adaptive references translation ▸
3Adaptive setup · uncertainty & disturbance
Clarifier-shaped: the real Clarifier Agent asks exactly this — does anything unmodeled or external act on the plant, which state's equation does it enter, and is the expression known. Answer here to give it a head start; it will confirm with you again in a short chat before the pipeline runs.
Uncertainty — an unmodeled term that's a function of the states
e.g. an unmodeled friction, catalyst aging, or drag term that enters one state's equation as a function of the states.
Disturbance — an external term that's a function of time
e.g. wind gusts, ambient/feed swings, or motor ripple — something acting on the plant from outside, as a function of t.
Design method preference (optional)
The Designer Agent only ever sees designer_view(spec) — states, equations, inputs, outputs. This preference is not sent to it; the method is picked from plant structure alone (output = states[0] and strict-feedback ⇒ backstepping, otherwise SMC). It's recorded on the run for reference only.
Tuner Agent — auto-tune after the baseline build
Simulate → score → adjust, capped at 4 rounds, ≤3 params/round.
